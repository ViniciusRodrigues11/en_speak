# En Speak

Aplicativo web para brasileiros praticarem *speaking* e *listening* em inglês por meio de diálogos guiados.

## Estrutura

- `front/`: aplicação React do MVP.
- `back/`: reservado para login social, sincronização e recursos pagos no futuro.
- `PLANO.md`: decisões de produto e etapas planejadas.

## Frontend

Stack inicial:

- React e TypeScript;
- Vite;
- Tailwind CSS;
- TanStack Router;
- componentes locais seguindo o padrão do shadcn/ui.

Para executar:

```bash
cd front
npm install
npm run dev
```

Para validar o build de produção:

```bash
cd front
npm run build
```
